# Project Journal (프로젝트 저널 — 맥락·턴·대화·마인드맵 트래커)

중장기 개인 프로젝트의 의도·생각 보존과 협업 상대와의 대화·턴·완료 추적, 가로 날짜 타임라인, 트리 마인드맵, 자유 배치 마인드맵을 제공하는 **독립 실행형 풀스택 웹 애플리케이션**입니다.

## 주요 기능
- **개인 비공개(`SOLO`) & 범용 협업(`COLLAB`)**:
  - 사내 직원 목록 대신 **초대 링크/초대 코드 공유** 또는 **이메일 초대**를 통해 가입 멤버 간 실시간 협업 지원
  - 앱 미가입 외부인(거래처·변호사·가족 등)과의 소통은 **관계자 사전 설정 프리셋**으로 원클릭 기록
  - 협업 멤버 간에는 로그인한 사용자 기준으로 `내 턴` / `상대 대기`가 자동 반전 표시
- **초고속 3초 인박스**: 떠오른 메모를 분류 없이 먼저 던져두고 나중에 프로젝트 타임라인·아이디어로 배치
- **통합 타임라인 + 완료 대상 추적**: `나 / 상대방(메신저형 말풍선) / 내 의도·결정 / 아이디어 / 완료 기록`을 한 타임라인에서 관리하고, 완료 시 특정 기록·아이디어를 지정 가능
- **3가지 시각화 뷰**:
  1. **가로 날짜 타임라인**: 프로젝트별 기록 노드(아이콘 구분), 진행 실선, 방치 경과 점선, 미래 Next Step 예정 다이아몬드
  2. **트리 마인드맵**: 좌→우 계층 구조, 아이디어 다단계 분기, 상호 연결(`🔗`), Next Step 승격
  3. **자유 마인드맵**: 중앙 방사형 배치, 자유 드래그 앤 드롭, `[노드 연결]` 4방향 포트 드래그 연결, `[노드 종속]` 겹쳐서 계층 종속, 프로젝트 추가 내용 자동 반영

## 로컬 실행 방법 (기본 포트: Client `5174`, Server `4100`)

```bash
# 1. 전체 의존성 설치
npm run install:all

# 2. 개발 서버 동시 실행 (Server 4100 + Client 5174)
npm run dev
```

브라우저에서 `http://localhost:5174` 를 열면 회원가입/로그인 및 **1클릭 데모 체험**을 바로 시작할 수 있습니다.

## 프로덕션 빌드 & 실행
```bash
npm run build
npm start
```
(`server/src/index.ts`가 `client/dist` 정적 파일을 함께 서빙하므로 단일 서버로 배포할 수 있습니다.)
