## 1. 의도 요약 (Statement of Intent)

- **목표 (Outcome)**: `mindmap` 공유 스페이스의 `공유 스페이스 설정 & 멤버 초대` 모달에서 양력·한국 음력 기념일을 등록·관리하고, 공유 캘린더 날짜 셀 + 접기/펼치기 가능한 상단 D-Day 요약 바(`D-` / `D-Day` / `D+`) + 기념일별 선택 웹 푸시 알림(한/일/영) 및 온디맨드 번역을 제공한다.
- **대상 (User)**: `mindmap` 공유 스페이스에 참여 중인 모든 멤버(방장·일반 멤버 구분 없이 누구나 추가·수정·삭제 가능).
- **배경 (Why now)**: 생일·결혼기념일·주요 기준일(한국 음력 포함)을 일반 일정과 별도로 매년 반복 관리하면서, 오늘 기준 남은/지난 D-Day를 캘린더에서 바로 보고 놓치지 않기 위함.
- **완료 기준 (Success)**:
  1. **기념일 관리 (`공유 스페이스 설정 & 멤버 초대` 모달)**:
     - 스페이스 멤버 누구나 기념일을 추가·수정·삭제할 수 있다.
     - 입력 항목: 제목, 메모(선택), 양력/음력(한국) 전환, 윤달 체크(음력 선택 시), 기준 날짜(`YYYY-MM-DD`), 매년 반복 ON/OFF, 알림 시점 선택(없음 / 당일 / 1일 전 / 3일 전 / 7일 전 등).
  2. **한국 음력 변환 및 예외 보정**:
     - 기본값은 양력이며, `한국어(ko)`·`일본어(ja)`·`영어(en)` 전 언어 UI에서 동일하게 양력/음력(한국) 선택 및 표시가 동작한다.
     - 한국 천문연구원(KARI/KST) 기준 음력-양력 변환을 적용한다.
     - 윤달로 등록된 매년 반복 기념일이 해당 연도에 같은 윤달이 없으면 **평달 같은 월·일**로 보정해 표시한다.
     - 음력 30일로 등록된 기념일이 해당 연도 작은달(29일까지)인 경우 **29일**로 보정해 표시한다.
  3. **D-Day 계산 및 표시**:
     - 모든 D-Day 계산은 **단순 날짜 차이(`D-1` / `D-Day` / `D+1`)**로 통일한다.
     - **매년 반복 ON**: 매년 해당 양력(또는 음력→양력 환산) 날짜에 캘린더 표시 + D-Day 바에서 다가오는 기념일(`D-N` / `D-Day`)과 기준일 경과(`D+N`)를 함께 확인 가능.
     - **매년 반복 OFF**: 해당 날짜에 1회 표시 + 기준일 전엔 `D-N`, 당일 `D-Day`, 지난 후엔 `D+N`으로 양방향 자동 카운트.
  4. **공유 캘린더 UI**:
     - 캘린더 상단에 **접기/펼치기 가능한 D-Day 요약 바**를 배치하고, 마지막 접힘/펼침 상태를 영구 저장(`localStorage`)해 다음 접속 시에도 그대로 유지한다.
     - 캘린더 각 날짜 셀에도 해당 날짜의 기념일을 시각적으로 표시한다.
  5. **푸시 알림 & 온디맨드 번역**:
     - 기념일별로 선택한 알림 시점에 해당 스페이스 멤버에게 **한국어(`ko`)·일본어(`ja`)·영어(`en`) 3개 언어 웹 푸시 알림**을 발송하며, 서버 재시작 등에도 중복 발송되지 않도록 이력을 관리한다(JST 기준).
     - 기념일 제목/메모에 **온디맨드 번역(`useContentTranslation` + `TranslateButton`)**을 제공한다.
- **제약 조건 (Constraint)**:
  - 모든 날짜·시간·D-Day 계산 및 알림 스케줄링은 **JST(`Asia/Tokyo`, UTC+9)** 기준을 따른다.
  - 한국 음력 변환은 한국 천문 기준(KST/KARI)을 준수한다.
  - PC 팝업 모달은 바깥 클릭 및 `Escape` 키로 닫히지 않도록 유지한다.
- **하지 않을 것 (Out of scope)**:
  - `NYGC` 저장소 반영 (이번 작업은 `mindmap`(`project-journal`) 단독 적용).
  - 커플 100일용 "당일을 1일로 계산(`+1일`)" 예외 토글.
  - 기념일 전용 댓글/채팅 및 일정 투표 기능(기존 일반 일정 기능과의 중복).
