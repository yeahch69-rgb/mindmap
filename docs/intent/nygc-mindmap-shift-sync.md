## 1. 의도 요약 (Statement of Intent)

- **목표 (Outcome)**: `NYGC`에서 Admin이 **프로필 설정 안에서 지정한 1개 계정의 근무 유형 시프트**를 비공개 토큰 기반 서버 간 단방향 연동(Pull)으로 `mindmap` DB에 자동 동기화하고, Admin이 선택한 `mindmap` 공유 스페이스 캘린더에 NYGC와 동일한 컴팩트 배지로 표시하며 시프트 변경 시 3개 언어 웹 푸시 알림을 발송한다.
- **대상 (User)**:
  - **연동 설정·관리**: 양쪽 사이트 모두 오직 `Admin`만 접근·노출 (일반 회원에게는 설정 UI/기능 자체가 보이지 않음).
  - **시프트 열람·알림 수신**: `mindmap`에서 Admin이 시프트 표시를 활성화한 특정 공유 스페이스(복수 선택 가능)의 참여 멤버 전원(본인 + 일본인 아내).
- **배경 (Why now)**: 아내가 회사 소속이 아니어서 NYGC에 초대할 수 없고, 현재 종이로 인쇄해 붙여두고 확인하는 출근 시프트를 두 사람이 쓰는 `mindmap` 공유 캘린더에서 실시간에 가깝게 바로 확인하고 변동도 놓치지 않기 위함.
- **완료 기준 (Success)**:
  1. **NYGC (발신 측 — Admin 프로필 설정 내 전용 섹션)**:
     - NYGC의 **Admin 프로필 설정** 안에서 ① 시프트를 연동할 **NYGC 대상 계정 1명 지정**(관리자 계정과 시프트 입력용 일반 사원 계정이 분리된 환경 대응), ② 비공개 연동 토큰 발급·재발급·해제 및 피드 URL 복사 기능을 제공한다.
     - 읽기 전용 피드 API는 유효한 토큰이 있을 때 오직 지정된 1개 계정의 `work_date`, `shift_type`, `secondary_shift_type`만 반환한다(출근 시각·사내 메모·부서명·타 직원 데이터 완전 제외).
  2. **Mindmap (수신 측 — Admin 전용 설정)**:
     - Admin 전용 설정 화면에서 NYGC 피드 URL·토큰 등록, 시프트를 표시할 공유 스페이스 복수 선택, 연동 ON/OFF, 마지막 동기화 시각/상태 확인 및 **수동 즉시 동기화 버튼**을 제공한다.
  3. **자동 동기화 & 캐시**:
     - Mindmap 서버가 15~30분 주기로 자동 동기화해 로컬 SQLite DB(및 Firebase 클라우드 백업)에 캐시하므로, NYGC 서버가 슬립/오프라인 상태여도 캘린더에 즉시 표시된다.
  4. **공유 캘린더 표시**:
     - 활성화된 스페이스의 달력 날짜 셀에 NYGC 공유 캘린더와 동일한 1~2글자 컴팩트 배지(한/일/영 자동 대응: 예 `출`/`出`/`In`, `휴`/`休`/`Off`, 보조 유형 포함)를 기존 기념일 배지·일정 바와 겹치지 않게 표시한다.
  5. **변경 푸시 알림 (3개 언어)**:
     - 최초 연동(초기 적재) 시에는 알림을 생략하고, 이후 동기화에서 기존 시프트의 추가/변경/삭제가 감지되면 변경분을 **1건으로 요약 묶음**해 활성 스페이스 멤버에게 **한국어(`ko`)·일본어(`ja`)·영어(`en`) 웹 푸시 알림**을 발송한다(서버 재시작 시 중복 발송 방지, JST 기준).
- **제약 조건 (Constraint)**:
  - **보안 최소화**: 전송 데이터는 오직 NYGC Admin이 명시적으로 지정한 1개 계정의 날짜 + 근무 유형(주/보조)뿐이며, 토큰은 서버 DB/클라우드 백업에 안전하게 저장되고 언제든 재발급/폐기 가능해야 한다.
  - **JST 준수**: 모든 날짜·동기화 기준·알림 처리는 **JST(`Asia/Tokyo`, UTC+9)** 기준을 따른다.
  - **UI 정책 준수**: `NYGC`와 `mindmap` 양쪽 모두 PC 팝업 모달 바깥 클릭/`Escape` 닫기 금지 및 네이티브 `alert`/`confirm`/`prompt` 금지 정책을 준수한다.
